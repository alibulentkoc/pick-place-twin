Open the twin

Lab and tractor twin

Two hydraulic cylinders hang from a bar and connect at the tip. The end effector hangs from the tip. Use this twin for the design project: find the geometry, the worst point, the cylinder forces and pressures, and the counterbalance valve settings.

For the design project, push Load tractor start. Then change the values to your design in step 2.

Step 2: enter your design

Push Open my design settings. Enter your values in these five folders:

  1. Arm geometry: pivot spacing, bar height, retracted length, stroke and gripper length. The gripper length is the grip length: the distance from the tip to the fruit center.
  2. Cylinders and hydraulics: bore, rod diameter, pressure (relief valve setting) and flow rate.
  3. Load: fruit shape, height (the fruit diameter) and weight. Enter the end effector weight as the gripper weight.
  4. Bin and pick width: select Show the bin, then enter the pick width, bin rim height, bin inner rim distance, bin width and rim clearance.
  5. Counterbalance valves: fitted or not, the setting in psi (or 0 to use the ratio), and the pilot ratio.

The Settings reference page explains each setting.

Step 3: check your design

Push Show worst point. The tip moves to the worst point of the full work path. The work path is each tip position from the pick line (grasp height, across the pick width) up to the drop height and across to the drop point. The worst point is the position where a cylinder force is the maximum. For many designs, the worst point is at the drop point above the bin, not on the pick line.

Then read these readouts:

Show answers. The twin hides pressures, speeds and areas, so that students calculate them first. After you calculate, select Show answers: pressures and speeds in Settings, View, and compare.

Reach region shows the shaded region that the tip can reach. Its color shows the cylinder force for each pound of load.

Collision stops

The frame legs stand beside the arm plane, so the arm can pass them. The two cylinders are on opposite sides of the arm plane, so they cannot touch. In all control modes, the twin stops a move if the gripper would hit the floor, the bar, an object or a bin wall. It also stops a move if a held fruit or a cylinder would hit a bin wall. The status line tells you which part would hit.

Counterbalance valves

  • Not fitted: a load that pulls the cylinder (an overrunning load) moves faster than the pump flow. The status line shows a warning. When the arm stops, the load drifts slowly because oil leaks through the valve spool.
  • Fitted: the valve holds the load. When the load lowers, the valve controls the speed. Readouts show the pilot pressure that opens the valve.
  • Setting too low: if the setting is less than the load pressure, the status line shows a warning. The valve opens and the load sinks.
  • Both ports: in this linkage, the force in a cylinder often changes from pull to push across the work path. Then each end holds the load in part of the path. The twin has a valve on each port (a dual valve), each set from the holding pressure of its own end. Read Cylinder 1 and 2 in the work path to see if your design needs this.

Step 4: run the arm (optional)

Manual
Hold the buttons or the keys to move each cylinder, as with the manual override of a solenoid valve. The sliders set the cylinder lengths directly, without hydraulics. Use this mode to learn how each cylinder moves the tip.
Camera auto
The camera finds the object and the controller does six pick checks. Then the controller moves the tip with on/off valve pulses. Pick one picks the nearest object. Pick all picks all objects.
Timed moves
No camera. Each valve opens for a calculated time. The real flow rate is different from the setting, so the tip misses the target. Compare the position error with Camera auto. This shows why feedback is necessary.

Camera auto works best when the two cylinders meet at a large angle. If the pivot spacing is small, the cylinders are almost parallel, and one valve pulse moves the tip a long way to the side. Then the jaws can hit the object or miss the grab. For such a design, use Manual to move the arm.

The six pick checks

Before a valve opens, the controller makes sure that the object is visible, it is on the arm plane, it is in the reach region, it is not too heavy, it fits between the jaws, and the drop spot is reachable. If a check fails, the pick stops. The status line tells you which check failed.

Stepped descent

Near the object, each cylinder moves one step or less (0.4 in by default). Then the other cylinder moves. Thus, the tip moves down almost straight, and the open jaws do not hit the object. Set Descent near objects to Direct to see the difference.

The circuit in this twin uses two tandem-center valves in series. The twin shows valve 2 with no flow while valve 1 is shifted. On real hardware, cylinder 2 can move on the return oil from cylinder 1. Remember this when you compare the twin with the trainer.
